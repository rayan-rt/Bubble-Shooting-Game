# Bubble Shooting Game

## Finding the Numbers

In this game, you have to shoot bubbles with the targeted Number. The game ends when you have shot all the bubbles or when you run out of time.

To win the game, you need to shoot all the bubbles within. You have 30 seconds to shoot all the bubbles.

### Technologies Used

- HTML
- CSS
- JavaScript
